# 0.5.3 整合測試

## 本次修正

- 模型本體與狀態燈共同旋轉 180 度（本地 yaw 90 改為 -90），修正從建築選單選取時背面朝向玩家。既有建築模型也會轉向，存檔的建築位置不改。
- 執行期取得元件改用引擎反射函式 K2_GetComponentsByClass；元件識別改用 UE4SS GetFullName。0.5.2 遊戲日誌證實 GetName 不可呼叫且工作燈未找到元件；原本本機 mock 未反映此 API 差異。
- 建築／科技圖示改為這台 Blender 模型的渲染圖。
- 進出艙內晶石圖案使用雙面材質，處理遊戲內缺失的單面圖案。

## 本輪遊戲測試

1. 從 B 選取建築，確認正面晶圓朝向玩家；放置、施工與完工材質正常。
2. 下多顆訂單，觀察工作燈切換及每顆約一秒；完成／取消後回待機。
3. 供電不足時確認停止產出，恢復供電後續作，沒有多扣原料或重複產出。
4. 訂單中存檔退出再載入，確認數量／進度／待領物品；未領取成品再載入也要確認。
5. 科技 74 級的位置及新圖示。
