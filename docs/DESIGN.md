# Awakening Crystal Converter：0.5.0 測試規格

2026-09-11 更新。最新需求採基地供電，取消封裝帕魯、六槽、六罐、適應性計分與鎖定功能。

## 兌換

九屬性跨屬性一換一。先選想取得的屬性，再選支付晶石與數量。供電正常時設定每顆 1 秒；材料扣除、剩餘數量、取消與領取交由原生 ConvertItem 模型。原版輝石製作配方不變。

## 電力

使用者指定以 3,000／秒為計算基準；這是本模組的數值需求，並非本次對網頁原版數據的認證。

- 無待製數量：36,000／秒（12 倍），待機也耗電。
- 有待製數量：總耗電 576,000／秒（192 倍），不另加待機耗電。
- 缺電而訂單尚未完成：維持工作負載要求，原生供電狀態決定能否生產。
- 完成或取消：回到 36,000／秒。
- 不需要派工帕魯；不自訂 SAN、飢餓或適應性計算。

原生 EnergyModule 已存在時，每 100 ms 在伺服端遊戲執行緒設定並讀回 ConsumeEnergySpeed、CurrentConsumeEnergySpeed、bRequiredConsumeEnergy。JSON 設定 Electric 與基準 36,000。缺失模組只記錄，不另建立私人原生模組。遊戲內耗電、缺電停工與存檔重載仍須實測。

## 科技與建造

普通科技 74 級，科技點 3，Tier 沿用原版 0。與古代文明遺物轉換器同級；technology_order.lua 在原生回傳清單將本機台移至其後，不改科技解鎖或點數。最終畫面排序仍待科技頁實測確認。建造工作量 1,000,000。四項材料數量為原版三倍：

| 材料 | 原版物品 ID | 數量 |
|---|---|---:|
| 帕魯樹晶錠 | WorldTreeIngot | 150 |
| 神秘木材 | Wood_WorldTree | 150 |
| 古代文明部件 | PalCrystal_Ex | 90 |
| 古代文明核心 | AncientParts2 | 60 |

材料 ID 與原版數量從已抽取的原版 DT_BuildObjectDataTable_Common 副本獨立讀回。科技 row 的 12 屬性 unversioned header 為 0x1980、zero mask 0x05e2；對照 SDK 欄位，LevelCap=74、Tier=0、Cost=3。

## 外觀

白色晶圓製程機身、圓形虹彩晶圓及方格晶粒、機械臂、控制面板、FORMOSA / TAIWAN 標牌；兩側晶石投入／輸出及能量連接結構。沒有封裝罐，也沒有帕魯模型。供電且正在兌換時能量節點為黃光，其他時間為待機色。

## 舊版相容

保留既有 PAE_ExchangePrototype ID 與 72 個配方 ID。獨立單槽 CoreProbe 測試建築及取回腳本保留，只為既有存檔能取回其中的帕魯；新版完全不依賴它。

## 驗證界線

本機測試涵蓋實際 power.lua 狀態切換、保護條件與重複視覺切換，以及既有目標優先 UI 回歸。引擎資產建置與資料匯入不等於遊戲功能驗證；具體安裝與遊戲復原狀態以 build 的讀回紀錄為準。
